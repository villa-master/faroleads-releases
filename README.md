# Faro Leads: Releases

Repositório **público** que hospeda os instaladores e o feed de auto-update do [Faro Leads](https://www.faroleads.site), app desktop Windows de prospecção B2B.

- Download: [última versão](https://github.com/villamasterperformance/faroleads-releases/releases/latest)
- O app instalado consulta este repo para atualizar sozinho.

> Não apagar nem tornar privado: isso quebra o auto-update dos clientes.
> O código-fonte fica em `faroleads-app` (privado).
